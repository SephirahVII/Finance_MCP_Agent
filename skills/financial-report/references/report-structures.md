# Financial Report Structures

## company_research

Required sections:

1. Company Profile
   - Company name, ticker, exchange, industry, main business if provided.
2. Recent Data Snapshot
   - Industry, latest close, year high/low, market value, total shares, book value per share.
3. Event Description
   - Company announcements, operating revenue, net profit attributable to parent, growth rates, disclosure period.
4. Event Commentary
   - Recent business progress, company-specific news, industry news, macro news, and their plausible impact.
5. Earnings Forecast
   - Revenue, net profit attributable to parent, PE. Include forecast assumptions and mark missing data.
6. Valuation and Risk
   - Valuation level, sensitivity, key risks.
7. Data Limitations and Disclaimer

## industry_research

Required sections:

1. Investment Highlights
   - Related industry news, macro news, price tracking, core industry changes.
2. Industry Basics
   - Closing level, 52-week high/low, relative index performance, sample universe.
3. Market Review
   - Recent industry index movement, constituent performance, volume/turnover if available.
4. Drivers and Risks
   - Policy, demand, supply, cost, liquidity, valuation, data gaps.
5. Disclaimer

## macro_research

Required sections:

1. Core Macro View
   - Main conclusion and time range.
2. Key Indicators
   - GDP, CPI/PPI, PMI, rates, credit, employment, fiscal, trade, if supplied.
3. Policy and Liquidity
   - Central bank, fiscal policy, liquidity, rates.
4. Asset Implications
   - Equities, bonds, commodities, FX, sectors, with caveats.
5. Risks and Data Limitations

## stock_technical_analysis

Required sections:

1. Scope and Instrument
   - Ticker, name, date range, data source.
2. Core Technical View
   - Trend, support/resistance if supplied, risk tone.
3. Price and Return
   - Start/end close, return, high/low, drawdown.
4. Volume and Volatility
   - Turnover/amount, volatility, notable sessions.
5. Indicators
   - MA, RSI, MACD, Bollinger, volume indicators. Only discuss indicators present in data.
6. Chart Interpretation
   - Place chart references near the relevant section.
7. Risk and Disclaimer

## company_valuation

Required sections:

1. Valuation Scope
   - Company, date range, valuation date, available data.
2. Fundamental Base
   - Revenue, margins, profits, cash flow, balance sheet if supplied.
3. DCF Valuation
   - Free cash flow, WACC, terminal growth, terminal value, sensitivity. If assumptions are missing, state what is needed.
4. Comparable Valuation
   - PE/PB/PS/EV metrics and peer comparison if supplied.
5. Value Assessment
   - Valuation range, upside/downside conditions, risk factors.
6. Disclaimer

## stock_investment_recommendation

Required sections:

1. Conclusion
   - Cautious overall assessment, not direct advice.
2. Technical Assessment
   - Trend, momentum, volatility, volume.
3. Value Assessment
   - DCF/comparable/fundamental valuation if supplied.
4. Scenario Analysis
   - Bull/base/bear scenarios and triggers.
5. Key Risks
6. Suitability and Disclaimer
